## 안녕하세요!

이 블로그는 IT 기술 전반에 대한 이야기를 나누는 공간입니다.

### 다룰 주제들

- **웹 개발**: Frontend, Backend, DevOps
- **클라우드**: AWS, GCP, Azure
- **AI/ML**: 머신러닝, 딥러닝, LLM
- **보안**: 웹 보안, 인프라 보안
- **개발 문화**: 코드 리뷰, 애자일, 생산성

### 기술 스택

이 블로그는 다음 기술로 만들어졌습니다:

```
- 정적 사이트 생성기: Hugo
- 테마: PaperMod
- 호스팅: GitHub Pages
- CI/CD: GitHub Actions
- 콘텐츠: Markdown
```

앞으로 유용한 글들을 많이 올릴 예정이니 기대해 주세요!
